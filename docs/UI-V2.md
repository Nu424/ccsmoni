# UI v2 設計（タイル基本＋時間軸ナビゲーション）

> 2026-10-27 のフィードバックを受けて、ダッシュボードを作り直すための仕様。v1（`static/` の現行の UI）との後方互換は考えない。
> 元になったプロトタイプ: `prototypes/b-tiles.*`（基本）、`prototypes/a-matrix.*`（5h レーン）。課題の整理は `prototypes/BRIEF.md`。

## 方針

- **主役は「アカウントごとに、どれくらい使っているか」を個別に見ること**。比較は二の次（ユーザーの判断）。
- 基本の表示は**タイル（並べる）**。比較したいときは**重ねる**に切り替える。重ねる表示では、下に A 案のような**アカウントごとの 5h レーン**を常に出す。
- 時間軸は自由に動かせる（ドラッグで範囲を絞る、軸の上でスクロールして拡大縮小・移動）。24h／7日／30日はプリセットとして残す。
- 使っていて楽しく、気が利いていること。操作の結果がすぐ目に見え、元に戻す方法が常にわかること。

## 画面の構成

```
┌ ヘッダー ─────────────────────────────────────────────────────────────┐
│ ccsmoni  推移｜設定   [✓問題なし 2/6][⊗ログイン切れ 1][▲上限見込み 2][💡使い残し 1]  │
│                         最終更新 2分前・次回 5分後 [今すぐ更新] [◐]           │
├ ツールバー ───────────────────────────────────────────────────────────┤
│ [24h|7日|30日]  10/24(金) 03:00 – 10/27(月) 05:55  [✕ プリセットに戻る]   │
│                                      [並べる|重ねる]   ページ ● ● ○        │
├ 本体 ────────────────────────────────────────────────────────────────┤
│  並べる: タイルのグリッド（1画面に収める）                                 │
│  重ねる: 週間の重ね合わせ（大）＋ 5h レーン（アカウントごとに1行）           │
├ 時間軸のストリップ（全タイル共通の x 軸。スクロール・ドラッグの操作面）──────┤
└ 凡例の1行（記号の読み方）────────────────────────────────────────────┘
```

### タイル（B 案ベース）
- 中身は、名前と状態の帯｜大きな数字（週間・5h・ペース差・メーター）｜週ピークのミニ柱｜ミニチャート（週間の線＋点、5h の薄い面、リセット線、取得の抜け、エラーの区間）｜1行のヒント。
- 全タイルで、y 軸（0〜100%）と x 軸（表示範囲）を共有する。カーソルは全タイルで同期する。
- ログイン切れのタイルも大きさは変えない。グラフは残し、最後にわかった値を薄く表示し、ヒントの行に［ログイン］を出す。
- 無効なアカウントはタイルにしない（ヘッダーの「無効 n 件」から設定へ）。アーカイブ（履歴だけあるアカウント）は、重ねる表示の凡例にだけ、既定では非表示で出す。

### タイルの並べ方（件数が奇数のとき・多いとき）
UX の判断:
1. **1ページに出すタイル数の上限**を設定で選べる（`ui.tiles_per_page`。4／6／8／9／12、既定は 6）。上限は1画面に収まる大きさを保つためのもので、ページ分割は「件数が上限を超えたときだけ」行う。
2. **隙間を作らない**: 列の数は、そのページの件数から決める（1→1、2→2、3→3、4→2×2、5・6→3列、7・8→4列、9→3×3、10〜12→4列）。最後の段が埋まらないときは、**最後の段のタイルを横に広げて段を埋める**（CSS grid で列を細かく割り、span を変える。例: 5件なら 6分割のグリッドで上段 span 2×3、下段 span 3×2）。空いたマスに別のパネルを入れることはしない（意味のない飾りを置かない）。
3. **小さくなりすぎない**: タイルの最小サイズ（目安 300×230px）を割る場合は、1画面に収めることをやめて縦にスクロールする（スマホ・狭い窓）。ページ分割の判断は件数と上限だけで行い、窓の大きさでページ数が変わらないようにする（メンタルモデルを安定させるため）。
4. **ページの切り替え**: ツールバーのページ表示は、各ページに含まれるアカウントの色の点で示す（どのページに誰がいるかがわかる）。←→ キー、スマホではスワイプで切り替える。切り替えのアニメーションは短く（150ms 程度の横スライド）。
5. **バッジとの連動**: ヘッダーのバッジにホバーすると、該当するアカウントのタイルが強調され、他は薄くなる（B 案のもの）。該当するアカウントが別のページにいるときは、そのページの点を光らせる。バッジを押すと、該当するアカウントのいる最初のページに移る。
6. 並び順は設定の順。勝手に並べ替えない（いつも同じ場所に同じアカウントがいる）。

### 重ねる表示（比較用）
- 上: 週間（または 5h を選べる）の重ね合わせ。点付き、終端に「値＋名前」の直接ラベル（重ならないよう配置）。
- 下: **アカウントごとの 5h レーン**（A 案。1行 = 高さ 16〜22px の面）。上のグラフと x 軸を共有する。
- 上部に、アカウントごとの今の値の帯（凡例を兼ねる。押すと表示／非表示、ダブルクリックでそれだけ表示、ホバーで強調）。

## 時間軸のナビゲーション（全表示で共通）

状態は1つの **TimeViewport**（`{start, end, preset | null, follow}`）に集約し、すべてのグラフ（タイル・重ね合わせ・5h レーン）が同じものを見る。

| 操作 | 結果 |
|---|---|
| プリセット［24h／7日／30日］ | その範囲（終端は「今」）。`follow=true` で、時間がたつと右端が今に追従する |
| グラフ上を横にドラッグ | 選択範囲を薄く表示し、離すとその範囲に拡大（どのタイルでドラッグしても、全タイルに効く） |
| 時間軸のストリップの上でホイール | カーソル位置を中心に拡大・縮小 |
| 時間軸のストリップを横にドラッグ／Shift+ホイール／トラックパッドの横スクロール | 移動（パン） |
| グラフ上で Ctrl+ホイール | 拡大・縮小（ブラウザのズームは止める） |
| グラフをダブルクリック／Esc／［✕ プリセットに戻る］ | 直前のプリセットに戻る |
| スマホ: 2本指のピンチ・横スワイプ（時間軸の上） | 拡大縮小・移動 |

- 表示範囲の制約: 最小 30 分、最大 120 日。未来には行かない（右端は「今」まで）。右端が今にくっついているあいだは、`follow` を維持する。
- プリセットから外れたら、ツールバーに範囲（`10/24(金) 03:00 – 10/27(月) 05:55`）と［✕ プリセットに戻る］を出す。プリセットのボタンは非選択の表示になる。
- 範囲の変化は、アニメーションでなめらかに見せる（150ms 程度の補間。連続ホイールでは即時）。
- 点の描き方は、表示範囲の画素密度で決める（点の間隔が 6px 以上なら全点、それ未満なら値が変わった点だけ、さらに密なら終端だけ）。
- データの取得: 表示範囲に前後の余白を足した範囲を `/api/history?since=&until=` で取得し、手元にキャッシュして結合する。移動のたびに通信が走らないよう、範囲の2倍の分をまとめて取る。取得中は軽いローディング表示にする。
- 表示範囲（プリセットか独自の範囲か）と、並べる／重ねるの選択は localStorage に保存する（try/catch）。独自の範囲は、再読み込みしたらプリセットに戻す。

## 色
- アカウントの色は**検証済みの7色**（dataviz の validator でライト・ダークとも隣接ペアに合格）。赤は使わない。状態の色（警告・危険）とは別系列。
  - light: `#2a78d6,#eb6834,#1baf7a,#eda100,#e87ba4,#008300,#6250d6`
  - dark:  `#3987e5,#d95926,#199e70,#c98500,#d55181,#008300,#9085e9`
- サーバーは hex ではなく**色の番号（color_slot）**を返し、UI がテーマに応じた色を使う。設定でユーザーが独自の色（#rrggbb）を指定した場合は、その色を両方のテーマで使う。
- 状態は、色・アイコン・文言の3つで示す。テキストはアカウントの色で塗らない。

## API の変更（サーバー担当が実装する。UI はこの形を前提にする）
- `GET /api/history`: `range` に加えて `since` / `until`（epoch 秒）を受け付ける（両方指定したら range より優先。範囲は最大 120 日。超えたら 422）。応答の形は今と同じ。
- `GET /api/state`
  - `palette: {"light": [...7], "dark": [...7]}`
  - `accounts[].color_slot: int | null`、`accounts[].color: "#rrggbb" | null`（独自の色を指定したときだけ。それ以外は null）。`archived[]` も同じ形にする。
  - `accounts[].status_since: epoch | null`（ok 以外の状態が続いている場合、その開始時刻）
  - `accounts[].weekly_peaks: [{resets_at, peak_percent, current: bool}]`（直近6枠、古い順。タイルのミニ柱に使う。/api/windows を毎回呼ばなくて済むように）
  - `ui.tiles_per_page`
- 設定（TOML）
  - `ui.tiles_per_page`（4／6／8／9／12、既定 6）
  - `accounts[].color`: 省略（自動）／整数 0〜6（パレットの番号）／"#rrggbb"（独自）
  - `GET /api/config` の `palette` は `{"light","dark"}` の形にし、`colors` は廃止して、各アカウントの `color_slot` と `color` を返す。
